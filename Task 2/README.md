# Task 2: Exploratory Data Analysis (EDA)

## Objective
To perform a complete Exploratory Data Analysis (EDA) on the Titanic dataset using statistics and visualizations to uncover patterns, trends, correlations, and anomalies.

## Project Structure
```text
Task 2/
├── Task2_Exploratory_Data_Analysis.ipynb  # Fully executed Jupyter Notebook
├── eda_script.py                          # Automated Python EDA pipeline
├── titanic_eda_enhanced.csv               # Dataset with engineered EDA features
└── plots/                                 # Visualizations & Statistical Summaries
    ├── 01_summary_histograms.png
    ├── 02_numeric_boxplots.png
    ├── 03_boxplots_by_survival_class.png
    ├── 04_correlation_heatmap.png
    ├── 05_pairplot.png
    ├── 06_survival_demographics.png
    ├── 07_family_and_alone_analysis.png
    ├── 08_age_fare_joint_distribution.png
    ├── 09_plotly_3d_scatter.html
    ├── 10_plotly_sunburst_survival.html
    ├── numeric_summary_statistics.csv
    └── categorical_summary_statistics.csv
```

## How to Run
Run the python script to regenerate all plots, statistics, and notebook:
```bash
python eda_script.py
```
Or view the pre-computed notebook `Task2_Exploratory_Data_Analysis.ipynb`.
